# Supporting Material

This directory preserves material that is useful for provenance, integrity checks, historical validation, or deeper inspection but is **not** the primary path through the paper's evidence.

Start with the numbered directories under `../studies/` and `../CLAIM_TO_ARTIFACT.md`. Use this directory only when a study README or claim-map entry points here.

## Contents

- `provenance/` — source-tree coverage ledgers and package metadata.
- `validation_and_hardening/` — zero-call checks, hardening runs, falsification, and bounded validation branches.
- `related_work_audit/` — frozen literature/related-work audit material.
- `original_project_snapshot/` — preserved source snapshot material needed for provenance.
- `logs/` — historical execution logs retained for auditability.
- `figure_history/` — historical figure material; final figures live in `../figures/`.
- `legacy_scripts/` — historical helper scripts retained for completeness.
- `legacy_verification/` — superseded verification packaging retained for provenance. The supported current verifier is `../VERIFY.sh`.

Historical names inside these records are intentionally preserved. They should not be interpreted as the recommended navigation structure of the artifact.
